# Изучение 1С

Мой путь к профессии разработчика 1С.

## День 1

Изучено:
- Платформа и конфигурация 1С
- Переменные
- Условия
- Циклы
- Процедуры и функции
- Массивы

Практика:
- Расчёт зарплаты
- Расчёт скидки
- Работа с массивами



## День 2

Изучено:
- Справочники 1С
- Элементы справочника
- Реквизиты справочника
- Работа со справочником через код
- Поиск элемента по наименованию
- Ссылки на объекты 1С
- Получение реквизитов через ссылку
- Разница между Конфигуратором и 1С:Предприятием

Практика:
- Создан справочник "Товары"
- Добавлены реквизиты "Цена" и "Артикул"
- Создан элемент "Апельсин империал"
- Реализован поиск товара по наименованию
- Получены цена, наименование и артикул товара
- Выполнены расчёты с данными товара
- Реализована проверка цены товара через условие

## День 3

Изучено:
- Документы 1С
- Реквизиты документов
- Табличные части
- Ссылки на элементы справочников в табличных частях
- Проведение документов

Практика:
- Создан документ "ПоступлениеТоваров"
- Создан документ "ПродажаТоваров"
- Создана табличная часть "Товары"
- Добавлены товары в документ
- Реализован расчёт суммы документа
